# Experimental Data for Spatio-temporal Coupling Enables Ultrasonic Atomization of Extremely Viscous Liquids

## Overview

This repository provides experimental datasets supporting the investigation of viscosity-dependent ultrasonic atomization under non-contact acoustic excitation.

The datasets include droplet-size measurements and operating-condition records for silicone oils with different nominal dynamic viscosities.

These data support the experimental results presented in Fig. 8 of the associated manuscript submitted to *Ultrasonics Sonochemistry*.

## Experimental Parameters

- Working frequency: 28 kHz
- Liquid: Silicone oil
- Nominal viscosity range for droplet-size measurements: 1–2000 cP
- Driving settings: 5–35
- Droplet-size metric: Sauter mean diameter (D32), in μm

The physical definition and units of the driving settings are specified in the associated experimental methods.
